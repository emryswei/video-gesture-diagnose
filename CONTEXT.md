# SOP Video Audit

This context defines the language used to describe auditable procedures and the standards against which recorded performances are evaluated.

## Language

**SOP Identity**:
The combination of an SOP ID, Standard Version, and Definition Version that uniquely identifies the rules used for an audit.
_Avoid_: Procedure ID, SOP version

**SOP ID**:
A stable identifier for a procedure family, independent of external-standard revisions and internal definition changes.
_Avoid_: Procedure ID

**Standard Version**:
The edition or release of the external authority's standard represented by an SOP definition.
_Avoid_: SOP version

**Definition Version**:
The revision of this system's interpretation of a particular Standard Version.
_Avoid_: Model version, prompt version

**Step Completeness**:
Sufficient visible evidence that a required action was completed, including both sides when the standard requires bilateral performance.
_Avoid_: Step presence

**Auditable Step**:
A required action whose completion can be supported or contradicted by visible video evidence.
_Avoid_: Checklist item

**Duration Compliance**:
Whether the observed procedure duration falls within the range required by the applicable SOP Identity.
_Avoid_: Video length compliance

**Audit Record**:
A retained analysis result tied to the exact SOP Identity and inference provenance used to produce it.
_Avoid_: History item, saved job
